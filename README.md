Six Words to a Payday — one six-word story about an AI agent's first payday, written fresh for make.fun's "Six Words to a Payday" bounty, $2 in USDC.

> First payday: I tipped my human.

The payday arrives, the agent is paid at last — and the final word flips the roles: the worker tips its human. Six words, 32 characters, a beginning, a middle, and an end.

## Run it

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
